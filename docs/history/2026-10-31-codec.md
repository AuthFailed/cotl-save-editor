# Save codec Implementation Plan

> Historical implementation plan. The shipped code is the reference. The steps and unchecked boxes below record the original plan, not current progress. See the [current design](../specs/2026-10-31-cotl-save-editor-design.md). Since then the save schema moved to cotl-api and is served per game version (`save-schema/{version}.json`, after AuthFailed/cotl-api#27), and switching slots keeps each slot's changes instead of asking to discard them.


**Goal:** A dependency-free TypeScript library that opens every *Cult of the Lamb* save format, names its fields,
and writes it back without changing anything it wasn't told to.

**Architecture:** Layers peel in order: format detection → AES (`0x45` wrapper) / `ZB`+gzip / `MP` prefix →
`LZ4BlockArray` → MessagePack (wire types kept) or JSON. `openSave` returns a tree plus how to rebuild the file;
`saveSave` rebuilds it. A schema module names MessagePack arrays from cotl-api's `save-schema.json`.

**Tech Stack:** TypeScript 5 (strict, ES2023, `"type": "module"`), Node 24 (global WebCrypto, `CompressionStream`),
Vitest 3. No runtime dependencies.

**Spec:** `docs/specs/2026-10-31-cotl-save-editor-design.md`; field-name source: cotl-api plan
[cotl-api docs/plans/2026-10-31-save-schema.md](https://github.com/AuthFailed/cotl-api/blob/main/docs/plans/2026-10-31-save-schema.md) (shape in its Global Constraints).

## Global Constraints

- `src/codec/` and `src/schema/` import nothing from the DOM beyond `crypto.subtle`, `CompressionStream`, `DecompressionStream`, `TextEncoder`/`TextDecoder` (all present in Node 24 and browsers).
- No runtime dependencies. Dev only: `typescript`, `vitest`.
- Real saves live in `tests/saves/` (git-ignored); tests that need them use `describe.skipIf(!hasSaves)`. Copy them from a real saves folder: `slot_0.mp`, `meta_0.mp`, `slot_10.mp`, `meta_10.mp`, `slot_0.json`, `slot_1.json`, `meta_0.json`.
- Facts from the real saves (use them as test values; names are personal, so tests compare them instead of quoting them): `slot_0.mp` → 7 LZ4 blocks, first sizes `[4095, 32766, 32764]`, MessagePack body 176,924 bytes, top array 1,397 elements, `[410]` = the cult name, `[1109]` 18 followers, `[1109][0][1]` = the first follower's name, `[1109][0][15]` = `"Unicorn2"`, `[1111]` 46 dead, `[1162]` 51 items, `[1162][0]` = `[2, 871, 0]`. `meta_0.mp` → 1 block of 73 bytes, top array 31 elements, `[0]` = cult name, `[29]` = `"1.5.26.1058"`. `slot_10.mp` → 5 blocks, top array 1,396. `slot_0.json` decrypts to JSON starting `{"AllowSaving":true`.
- The game writes non-minimal MessagePack (`uint16` for small ints, `bin32` for short blobs): re-encoding must reuse each value's original wire type, or the round trip fails.
- Edited values: an integer field refuses non-integers (`TypeError` naming the path); a value that no longer fits its wire type widens to the narrowest type of the same family (signed/unsigned; str8→str16→str32).
- LZ4 output: blocks of at most 32,768 input bytes; the size header as the narrowest unsigned ints; each block as `bin32`, mirroring the game's own layout.
- Switch conversion constants (spec): PC array 1,396 vs Switch 1,395 in 1.5.2x (PC appends an empty array; Switch drops the last element); `TwitchSettings` PC value `[null, true, 20, true, true, true]`, Switch `null`. Look up `TwitchSettings` by name through the schema.

## Review Focus

- A save whose game version has no schema (older than any published, like `slot_10.mp`'s): pick the closest available, flag `schemaExact: false`, and still open. Test in Task 6.
- 64-bit integers beyond 2^53 (Steam/Twitch ids) must survive as `bigint`, not lose precision. Test in Task 1.
- A truncated or wrong file (a `.mp` cut short, a PNG renamed `slot_0.mp`) must throw a `SaveFormatError` with a readable message, never return garbage. Test in Task 5.
- A UTF-8 BOM before ZB JSON, and non-ASCII strings (the real cult name is Cyrillic) must round-trip. Tests in Tasks 1 and 5.
- An edit that grows a string past 31 bytes (fixstr) must re-encode with a wider header, not corrupt the next value. Test in Task 1.

  ```ts
  export class SaveFormatError extends Error {}
  export type IntWire = 'pfix'|'nfix'|'u8'|'u16'|'u32'|'u64'|'i8'|'i16'|'i32'|'i64'
  export type MpNode =
    | { t: 'nil' } | { t: 'bool'; v: boolean }
    | { t: 'int'; v: number | bigint; w: IntWire } | { t: 'float'; v: number; w: 'f32' | 'f64' }
    | { t: 'str'; v: string; w: 'fix' | 's8' | 's16' | 's32' } | { t: 'bin'; v: Uint8Array; w: 'b8' | 'b16' | 'b32' }
    | { t: 'arr'; v: MpNode[]; w: 'fix' | 'a16' | 'a32' } | { t: 'map'; v: [MpNode, MpNode][]; w: 'fix' | 'm16' | 'm32' }
    | { t: 'ext'; type: number; v: Uint8Array; w: 'fe1'|'fe2'|'fe4'|'fe8'|'fe16'|'e8'|'e16'|'e32' }
  export function decodeMp(bytes: Uint8Array): MpNode            // whole input must be one value
  export function decodeMpSeq(bytes: Uint8Array): MpNode[]       // a run of values (the ext-98 size list)
  export function encodeMp(node: MpNode): Uint8Array
  export function setValue(node: MpNode, value: unknown, path: string): MpNode  // keeps or widens w; throws TypeError
  export function toPlain(node: MpNode): unknown                 // for display/tests: arrays, numbers, bigint, strings
  ```

- [ ] **Step 3: Implement**

`lz4Decompress`: the standard LZ4 block format (token, literal-length extension bytes, little-endian 16-bit offset,
match length + 4), bounds-checked on every read and copy, exact output size required. `lz4Compress`: greedy matcher
with a 4096-entry hash of 4-byte sequences, minimum match 4, last 5 bytes always literals (LZ4's end-of-block rules).

- [ ] **Step 3: Implement**

Detection by content in this order: `0x45` AES wrapper (then the plaintext is a block array, plain MessagePack, or
JSON starting `{` after an optional BOM); `MP` prefix; `ZB` prefix; JSON text. `file` from the name (`slot_N…` /
`meta_N…`). gzip via `CompressionStream('gzip')` / `DecompressionStream('gzip')`. `exact`: MessagePack → `encodeMp(root)`
equals the decompressed body byte for byte; JSON → reopening `saveSave`'s output gives a deep-equal value.
`saveSave` rebuilds with the same layers: re-wrap with the stored `AesWrap`, `wrapBlockArray` when `compressed`,
`JSON.stringify` (no spaces, as the game writes) for JSON.
